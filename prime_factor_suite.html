Kho số nguyên tố (primes_store multi-file)

Số lượng (unique): 0
Lớn nhất: —
Nguồn: mặc định

Hỗ trợ multi-file: primes_store.json, primes_store_2.json … primes_store_20.json. File đã có trên máy: luôn cho nạp (kể cả >300 MB). Ngưỡng 300 MB chỉ khi lưu / thu thập mới — khuyên tách sang primes_store_X.json. Mỗi file tách biệt trong slot riêng; trial division mới ghép unique. Xuất file 02+ = chỉ primes của slot đó.
Continuity: file tiếp theo luôn được seed bằng max của file ngay trước (max file N = min file N+1) → chồng lấn ≥1 số, dedup mượt hơn. Sau F5 cần nạp lại thủ công. ≥4 file đầy đủ giúp trial division cho số rất lớn (>70 digits).

Đang phân tích định giá p-adic & tái cấu trúc...

Sắp xếp số tự nhiên theo xoắn ốc · đánh dấu số nguyên tố bằng điểm sáng. Các đường chéo/cong nổi bật liên quan đa thức sinh nguyên tố (vd. Euler n²+n+41).

So sánh hàm đếm số nguyên tố thực tế π(x) với xấp xỉ Định lý số nguyên tố x/ln(x) và li(x) (logarithmic integral). Dùng kho multi-file nếu đã nạp; không thì sieve tạm.

Máy tính lặp BigInt. Biến: a,b,c,n,i,m. Phép: + - * / %, modpow(base,exp,mod), gcd(x,y), fact(k). Ví dụ: a=1; for i=1..n: a=(a*a+1)%m

Giả thuyết Collatz: n chẵn → n/2 · n lẻ → 3n+1. Mọi n dương được cho là về 1. Nhập N → vẽ quỹ đạo và thống kê.

Lưu ý: không có thuật toán chuẩn lấy chữ số thập phân π trực tiếp từ phân tích thừa số. Suite hỗ trợ 3 cách gắn với thế mạnh app: (1) Tích Euler trên primes trong kho → xấp xỉ π; (2) BBP → chữ số hex thứ n (modPow); (3) Machin + BigInt → chữ số thập phân.

Pipeline: Trial + kho primes (multi-file) → (thu thập thêm nếu cần) → ECM → QS lite → Brent/Floyd Rho → p−1.
Multi-file store: nạp tối đa 20 file primes_store.json / primes_store_X.json (X=1–20). File đã có: luôn nạp được; >300 MB chỉ hạn chế khi lưu mới. Tự dedup giữa các file.
ECM (Lenstra): hiệu quả với thừa số ~12–22 chữ số.
QS lite: Quadratic Sieve rút gọn cho số ≤ ~36 chữ số khi ECM chưa ra.
≥4 file đầy đủ → trial division mạnh cho số >70 digits.
Ví dụ 45 digits: 3 × 293 × 7627999824241894379 × 46854393787450199552879 (ECM mạnh bắt thừa số ~19 digits; nếu quá lâu hãy dùng Python/sympy).
Xoắn ốc: Ulam (vuông) & Sacks (Archimedes) — trực quan hóa phân bố nguyên tố.
Định lý π(x): so sánh π(x) với x/ln(x) và li(x).
Lặp / Công thức: BigInt loop + modpow/gcd/fact → factor kết quả.
Collatz: quỹ đạo 3n+1 dạng biểu đồ.
Chữ số π: tích Euler (primes) · BBP hex · Machin thập phân.
